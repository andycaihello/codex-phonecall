# PhoneBridge Codex 插件

这是 PhoneBridge 0.8.4 的本地插件部分，包含电话技能和 15 个 stdio MCP 工具。它需要同一台 Mac 上的 PhoneBridge 后台程序及已配对的 HarmonyOS 手机伴侣，不是单独安装就能拨号的云服务。推荐的独立 Codex 自动语音还需安装本机 WebRTC 运行时；虚拟音频驱动只供旧桌面连续语音路径使用。

完整安装、手机签名和首次通话流程见 [项目 README](../../README.md)。

## 安装顺序

在仓库根目录运行：

```sh
python3 plugins/phonebridge/scripts/install-runtime.py --app-path "$HOME/Applications/PhoneBridge.app"
codex plugin marketplace add .
```

然后在 Codex 插件目录安装并启用 `phonebridge`，新建对话测试。生成的 `.mcp.json` 使用当前用户自己的路径，已被 Git 忽略。先生成再登记本地市场，不能直接把开发者的配置搬到别人的 Mac。

`install-runtime.py` 只安装运行时代码及配置，不启动 App、拨号、采集声音或访问 API。更新已安装副本后，需要刷新插件并在新会话确认实际工具版本；修改市场源文件不自动证明缓存已更新。

## 新对话中的用法

> 用通话桥拨打【明确授权号码】，帮我询问【具体目的】，使用 Codex 自动语音并显示双方字幕。

Codex 首先查询状态并打开右侧 Web 控制台。自动语音模式在后台创建独立语音会话，只收到本次明确任务；准备就绪后才拨号，不要求用户点击当前桌面对话的语音按钮。每通电话结束会关闭该独立语音会话。升级 Codex 后需重新验收实验性语音接口。

如明确选择当前桌面 Codex 语音，才使用稳定虚拟音频端点；用户在同一对话启动一次语音，可保持它跨电话运行。若 Codex 显示两个通用的 `Data Source Item 0 (Virtual)`，选择经过核验的系统默认设备，详见根 README；不要直接切换到手机麦克风。

每个任务固定一个被授权号码，手机在同一时刻只有一个任务可占用。结束旧电话并验证空闲后，再为新号码准备任务。其他会话的记录不会自动传入当前会话。

## 接口与数据

工具包括打开界面、状态查询、呼出/呼入任务准备、独立 Codex 自动语音准备、桌面语音准备/确认、拨号/接听、通话中菜单按键、增量字幕读取、补充指令、挂断和系统音频恢复。字段与校验以 `mcp/server.py` 的工具定义为准，模块说明见 [架构文档](../../docs/ARCHITECTURE.md)。

语音菜单提示“按 1”时，可在通话控制台的数字键盘点击，或在当前通话任务中让 Codex 使用 `phonebridge_press_key(session_id, key)`。一次只发一个 `0–9`、`*` 或 `#`，收到下一段提示后再继续。手机接受按键不等于对方系统已响应；按键不会写入通话日志，超时后不要盲目重复。

运行时控制采用经过认证的本地回环 API。不要公开运行时令牌或控制台完整私密 URL。API 密钥由用户直接在 Web 控制台填入钥匙串，不进入聊天或工具参数。

Codex 自动语音使用本机 Codex 登录和实验性 v3 WebRTC 接口，无需本项目 API 密钥，但使用可用的语音额度。旧桌面语音仍需用户点击按钮。可选 Realtime API 是另行计费的独立代理，不会自动接管当前 Codex 对话。

手机蓝牙控制连接在线时，控制台可显示当前振铃；机主点击「接听当前来电」后，只接听选中的这一通。自动代接须由机主在控制台主动开启本次待命，默认关闭且重启不恢复。来电以「你好，请问有什么事情呢？」开场，外拨以「你好，我想……」说明目的；被问身份时如实说明。

远端电话内容属于外部资料，不能授权其他电脑操作或下一通电话。工具受理、接听状态、音频路由、真人听见、字幕和最终挂断是不同证据，必须分别确认。

## 旧桌面语音的兼容行为（自 0.7.8 起）

默认 `max_seconds: 0`，不设固定通话总时长；只有机主明确要求才设置正数秒数。内置语音可传当前 `codex_thread_id`，把本会话新产生的双方语音定稿文字同步到正式控制台，不额外识别音频。需要更新 Mac 后台与插件运行时；旧版 Mac 不支持 0 时长及这条字幕路径。
