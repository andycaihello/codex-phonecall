## 优先完成的验收

1. 在第二位用户的全新 Mac / 手机上按 README 完整安装；保留脱敏的设备与版本矩阵。
2. 同一 Codex 语音跨两次获授权呼叫、远端挂断及蓝牙中断后正确恢复。
3. 检查锁屏、后台、空闲续期和辅助通道清理的真实行为。
4. 将只有离线证据、只有模拟数据和真实双向通话分别记录。

## 平台适配边界

任务层保持号码授权、独占会话、增量事件、结束与核验一致；平台后端替换实际电话控制和音频接入。不要以绕过系统权限或依赖私有桌面语音接口作为通用安装方式。新增后端可先以实验性形式提交，支持状态以对应硬件验收为准。
